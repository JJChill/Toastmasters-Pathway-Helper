# Glossary

The words used in this project, in the members' language. One term per concept; use these terms verbatim in
code, tests and the UI.

| Term | Meaning |
|------|---------|
| **Path** | A whole Toastmasters Pathways program, e.g. Presentation Mastery or Visionary Communication. |
| **Level** | A stage inside a path (Level 1 to Level 5). Done in order. |
| **Project** | A speech or assignment a member does in their club; a row on the Overview. |
| **Step** | A page inside a project (e.g. "Part 1: Get Started"). |
| **Required item** | A checklist, requirements or completion item that sits beside the projects ("Level 1: Mastering Fundamentals", "Level 1 Completion", "Reflect on Your Path"). Easy to miss; needed to finish the level. |
| **Elective** | A project the member chooses from a list instead of being assigned. |
| **Chooser** | The "Electives" row where a member picks their electives; it carries the minimum required. |
| **Picked elective** | An elective the member has chosen; shown indented under the chooser. |
| **Next** | The first thing a member still has to do. Derived by this tool; Base Camp only knows done or not done. |
| **Overview** | The page listing every level and project of a path, with its completion marks. |
| **Chip** | The small coloured label shown in front of a title (kind and status). |
| **After-speech step** | "Complete Your Project": filled in only after the speech has been given and evaluated. |
| **Before You Move On** | The last step of every project. Holds the **Complete My Project** button, which marks the project complete (it then reads "Your project is marked complete."). |
| **Level Completion** | The last row of a level ("Level N Completion"). The member chooses a club and presses **Submit** to send a level completion request to their Base Camp manager; Base Camp keeps Submit greyed out until every project in the level is complete. **Path Completion** is the same for the whole path, after the last level and "Reflect on Your Path". |
| **Evaluation Resource** | A printable PDF listed under a project step's resources. The member prints it for their evaluator to use when they give the speech. |
| **Base Camp** | The Toastmasters learning site this extension runs on. |
